\section{Observability computations for SIR, Lotka--Volterra, and OGTT}
\label{app:observability}

This appendix documents the calculations and code used to support the observability/identifiability statements in
Section~\ref{sec:identifiability}.
We treat parameters as augmented constant states and follow the nonlinear observability framework of Hermann and Krener~\cite{hermann1977nonlinear}.

\subsection{SIR model: Lie-derivative-based observability matrix}
\label{app:obs-sir}

Consistently with the main text (Section~\ref{sec:identifiability}) and with the experimental setup, we
eliminate the recovered compartment through the conservation law $R = N - S - I$ and observe the
\emph{susceptible} population. The effective augmented state and observation are thus
\[
z = (S,I,\beta,\gamma)\in\mathbb{R}^4,
\qquad
h(z)=S,
\]
with the augmented vector field (the normalized-incidence SIR dynamics, parameters treated as constant states)
\[
F(z) = (\dot S,\dot I,\dot\beta,\dot\gamma)
=
\Big(-\tfrac{\beta S I}{N},\ \tfrac{\beta S I}{N}-\gamma I,\ 0,\ 0\Big).
\]
The first Lie derivatives of $h=S$ along $F$ and their gradients are
\begin{align*}
L_F^0 h(z) &= S, & \nabla_z L_F^0 h &= (1,0,0,0),\\
L_F^1 h(z) &= -\tfrac{\beta S I}{N}, & \nabla_z L_F^1 h &= \Big(-\tfrac{\beta I}{N},\ -\tfrac{\beta S}{N},\ -\tfrac{SI}{N},\ 0\Big),
\end{align*}
and continuing through $L_F^2 h,\ L_F^3 h$ we assemble the observation map and the $4\times4$ observability matrix
\[
\Phi(z)=\big[\,L_F^0 h,\ L_F^1 h,\ L_F^2 h,\ L_F^3 h\,\big]^\top,
\qquad
\mathbf{O}(z) := \nabla_z \Phi(z)\in\mathbb{R}^{4\times 4}.
\]
The following \texttt{sympy} script constructs $\mathbf{O}(z)$ and evaluates its determinant symbolically:
\begin{verbatim}
import sympy as sp
S, I, beta, gamma, N = sp.symbols('S I beta gamma N', positive=True)
z = sp.Matrix([S, I, beta, gamma])
F = sp.Matrix([-beta*S*I/N, beta*S*I/N - gamma*I, 0, 0])
def Lie(expr):
    return (sp.Matrix([expr]).jacobian(z) * F)[0]
h = S
rows, cur = [h], h
for _ in range(3):
    cur = sp.expand(Lie(cur)); rows.append(cur)
O = sp.Matrix([list(sp.Matrix([r]).jacobian(z)) for r in rows])
print("det O_S =", sp.factor(sp.simplify(O.det())))   # I**3*S**4*beta**4/N**5
print("rank    =", O.rank())                           # 4
\end{verbatim}
Running it yields the closed-form determinant
\[
\det \mathbf{O}_S(z) \;=\; \frac{I^{3} S^{4}\,\beta^{4}}{N^{5}},
\]
which is nonzero for every generic state with $S,I,\beta\neq 0$; hence $\mathrm{rank}\,\mathbf{O}_S(z)=4$ and the
SIR system is locally weakly observable (locally identifiable at generic states) from $S(t)$ alone. For reference, the same construction with the
alternative observation $h(z)=I$ gives
\[
\det \mathbf{O}_I(z) \;=\; -\,\frac{I^{6} S\,\beta^{4}}{N^{5}},
\]
so the conclusion (rank $4$, generic observability) is identical although the algebra differs; the main text and
experiments use the $S$-only observation. We stress that this is a \emph{continuous-time} rank condition on exact
outputs and their derivatives; its relation to the finite, sparsely sampled observations actually available is
taken up in Section~\ref{sec:identifiability}.

\subsection{Lotka--Volterra model: symbolic rank deficiency}
\label{app:obs-lv}

For the Lotka--Volterra system we augment the state as
\[
z = (x,y,\alpha,\beta,\gamma,\delta),
\]
with vector field
\[
\Sigma(z) =
(\alpha x - \beta x y,\ \delta x y - \gamma y,\ 0,\ 0,\ 0,\ 0),
\]
and observation $h(z)=x$.

The following \texttt{sympy} script computes the observation matrix and its rank:

\begin{verbatim}
import sympy as sp

x, y, a, b, g, d = sp.symbols('x y a b g d')
z = sp.Matrix([x, y, a, b, g, d])

sigma = sp.Matrix([
    a*x - b*x*y,
    d*x*y - g*y,
    0, 0, 0, 0
])

h = x

Phi = []
current_L = h
Phi.append(current_L)

for _ in range(len(z) - 1):     # adds L^1..L^5 -> Phi = L^0..L^5 (6 rows)
    grad_L = sp.Matrix([current_L]).jacobian(z)
    current_L = (grad_L * sigma)[0]
    Phi.append(current_L)

O = sp.Matrix(Phi).jacobian(z)  # 6 x 6 observation matrix
print("rank(O) =", O.rank())
\end{verbatim}

Running this code yields \texttt{rank(O) = 5}, while the augmented state dimension is $6$.
Thus the observation matrix is rank-deficient and the Lotka--Volterra model is not locally observable from prey-only observations.
Figure~\ref{fig:lv_unidentifiable} in the main text provides a concrete example of two distinct states/parameters producing essentially identical $x(t)$.

\subsection{OGTT model: restricted sampled-sensitivity rank and conditioning}
\label{app:obs-ogtt}

For OGTT we analyze the sampled sensitivity on the free-variable manifold $\xi=(I_0,S_I,\sigma)$
(Section~\ref{subsec:ident-ogtt}): $G_0=G(t_0)$ is observed, and the incretin initial states are slaved to
$(N_{5,0},N_{6,0})=\mathrm{SS}(G_0,\sigma)$, so $\sigma$-perturbations recompute the steady state. We use
\emph{central} differences with a combined relative-plus-absolute step $h_k=\texttt{atol}+\texttt{rtol}\cdot|\xi_k|$;
a purely relative step $\mathrm{d}\xi_k=\xi_k\varepsilon$ would degenerate at $\xi_k=0$. Columns are
normalized by the $\xi$-scales so the singular-value comparison is dimensionless.

\begin{verbatim}
# xi = (I0, S_I, sigma); G0 fixed; (N5,N6)=SS(G0,sigma) recomputed in simulate_G
def restricted_jacobian(simulate_G, xi, times, rtol=1e-4, atol=1e-6):
    J = np.zeros((len(times), 3)); cs = np.abs(xi)
    for k in range(3):
        h = atol + rtol * abs(xi[k])       # never zero
        ep = xi.copy(); ep[k] += h
        em = xi.copy(); em[k] -= h
        dG = simulate_G(ep, times) - simulate_G(em, times)
        J[:, k] = dG / (2*h) * cs[k]
    S = np.linalg.svd(J, compute_uv=False)  # 5x3 Jacobian: <= 3 svals
    return S, S[0] / S[-1]                   # sing. values, cond. number
\end{verbatim}

Here \texttt{col\_scale}$_k=|\xi_k|$, so $J$ is the \emph{log-relative} Jacobian $D_\xi\mathcal{G}\,\operatorname{diag}(\xi)$
(columns $\partial G/\partial\log\xi_k$; glucose in raw mg/dL); this is a scale-invariant relative-coordinate
diagnostic, distinct from the network training coordinate (Appendix~\ref{app:repro-norm}). We evaluate at the
nominal point $G_0=91$~mg/dL, $\xi=(I_0,S_I,\sigma)=(6,0.5,0.5)$, and check stability across
\texttt{rtol}$\in[10^{-5},10^{-3}]$. We report two rank notions, since the reported $\varsigma_3$ is of the
same order as a naive $10^{-3}\varsigma_{\max}$ cutoff. \emph{(i) Algebraic rank}: under a machine-precision
tolerance $\tau_{\mathrm{alg}}=\max(m,n)\,\epsilon_{\mathrm{mach}}\,\varsigma_{\max}$ (here
$\approx5\times2.2\times10^{-16}\times73\approx8\times10^{-14}$) the step-size-stable $\varsigma_3$ is nonzero,
so $J$ has algebraic rank $3$. \emph{(ii) Practical effective rank}: at the deliberately coarser
relative-resolution threshold $10^{-3}\varsigma_{\max}\approx0.073$, the effective rank is borderline and may be
read as $2$ or $3$ depending on the evaluation point. At the five-point grid $J$ is $5\times3$ (its first row is
zero since $G(t_0)=G_0$ is fixed) and yields $\varsigma\approx(72.6,0.155,0.073)$ (ratios
$\varsigma_2/\varsigma_1\approx2.1\times10^{-3}$, $\varsigma_3/\varsigma_1\approx1.0\times10^{-3}$; condition
number $\approx10^3$): locally full \emph{algebraic} column rank $3$ but severely ill-conditioned, i.e.\ full
rank yet practically borderline rather than structurally rank-deficient. Under the constant-HGP ablation the third singular value drops to $\approx5\times10^{-5}$ and
its right singular vector coincides exactly with the scaling tangent $\hat t=(+1,-1,+1)/\sqrt3$ ($|\cos|=1.00$),
so the analytic rank is $\le2$. We make no claim about the continuous-time Hermann--Krener rank of the ambient
six-dimensional state; the finite five-point Jacobian ($\operatorname{rank}\le5$) cannot certify it.

\subsection{Homogeneity behind the constant-HGP scaling symmetry}
\label{app:obs-ogtt-sym}

We justify the exact symmetry $(I_0,S_I,\sigma)\mapsto(cI_0,S_I/c,c\sigma)$ used in Section~\ref{subsec:ident-ogtt}
for the constant-HGP model. Write the ISS insulin/incretin subsystem schematically as
\[
\dot I = \tfrac{b}{\mathrm{BV}}\,\mathrm{ISR}(N_5) - kI,\qquad
\dot N_5 = a_{55}N_5 + a_{56}N_6,\qquad
\dot N_6 = \sigma\,r(G) + a_{65}N_5 + a_{66}N_6,
\]
where the coefficients $a_{ij}$ and $r(G)$ depend on $G$ but not on $\sigma$ or $S_I$, and $\mathrm{ISR}$ is
\emph{linear} in $N_5$ (a product of $G$-dependent pool fractions times $N_5$; see \path{systems/ogtt_simul.py}).
The secretion parameter $\sigma$ enters only as a multiplicative gain on the incretin forcing $\sigma r(G)$.
Consequently the map $(I,N_5,N_6)\mapsto c\,(I,N_5,N_6)$ together with $\sigma\mapsto c\sigma$ leaves these
three equations invariant (each side scales by $c$), and the slaved steady state obeys
$\mathrm{SS}(G_0,c\sigma)=c\,\mathrm{SS}(G_0,\sigma)$ because it solves a linear system whose forcing is
$\propto\sigma$. Glucose couples to insulin only through the term $-(E_{G0}+S_I I)G$; under $I\mapsto cI$ and
$S_I\mapsto S_I/c$ the product $S_I I$ is invariant, and with constant HGP the entire glucose equation is
unchanged. Since $G(0)=G_0$ is held fixed, $G(t)$ is exactly invariant. (For the full ISS model, HGP depends on
$S_I$, so this invariance is only approximate --- the weak breaking quantified in Section~\ref{subsec:ident-ogtt}.)
